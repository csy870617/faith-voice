신앙일지 음성

신앙일지 앱의 자연스러운 음성 읽기에 쓰는 음성 모델 보관소입니다.

사용 방법신앙일지 앱 → 글 열기 → 음성 읽기 → 설정(⚙) → 자연음 내려받기
크기약 440MB (한 번만 받으면 인터넷 없이 사용)
음성 모델Supertonic 3 · Supertone Inc. · Open RAIL-M
실행 엔진onnxruntime-web 1.23.2 · Microsoft · MIT

원본 모델 내용은 바꾸지 않았습니다. CPU 기기용 8비트 판을 따로 만들어 두었고(README), 큰 파일은 GitHub 크기 제한 때문에 조각으로 나눠 두었습니다. 음성 모델과 이 모델로 만든 음성에는 Open RAIL-M 라이선스의 사용 제한(부록 A)이 적용됩니다.
